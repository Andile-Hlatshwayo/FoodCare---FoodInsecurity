# FoodCare - FoodInsecurity
Food insecurity tackling in SA
## Overview

This project is a South African-focused web application aimed at helping address food insecurity by making it easier for people to offer and access food assistance.

The platform provides a space where individuals can submit food donations, while administrators can review and manage the available donation information. The application is designed around the South African environment and can be expanded to support organisations, communities and people requiring assistance.

## Purpose

The main purpose of the system is to use technology to make food assistance easier to organise and access. It focuses on challenges such as food affordability, limited access to assistance and the need for better connections between donors and communities.

## Technologies

* ASP.NET Web Forms
* C#
* Microsoft Access
* HTML, CSS and JavaScript
* Responsive web design

## Current Features

* User registration and login
* Food donation submission
* Optional image uploads with donations
* Images stored directly in the Access database
* Administrator donation management
* Search functionality for donation records
* Success and error notification messages
* Responsive navigation for different screen sizes

## South African Focus

The application is developed specifically with South Africa in mind. Its information and functionality can be adapted to South African provinces, communities, organisations and local food-support initiatives.

The system considers food insecurity as a broader issue involving affordability, access, unemployment, inequality and the availability of support, rather than simply a lack of food.

## Database

The application uses Microsoft Access as its database. Donation information is stored in the `CustomerDonation` table.

Optional donation photographs are stored directly in the database as binary data rather than being stored only as file paths.

## Future Development

The application is intended to grow beyond donation management. Future functionality may include:

* Requests for food assistance
* Organisation and charity profiles
* Location-based assistance
* Food-support listings
* Donation status and tracking
* Connecting people in need with available assistance
* Additional South African community and government resources

## Project Status

**In Development**

The current version provides the foundation for a larger platform that can eventually connect donors, organisations, communities and people experiencing food insecurity across South Africa.
